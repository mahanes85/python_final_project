# 🎟️ سیستم مدیریت رویداد و رزرو بلیت

یک برنامه دسکتاپ برای مدیریت رویدادها، مشتریان، رزرو بلیت و پرداخت‌ها، توسعه‌یافته با زبان برنامه‌نویسی Python و رابط گرافیکی Tkinter با استفاده از معماری لایه‌ای.

## 📋 فهرست مطالب

- ویژگی‌ها
- معماری پروژه
- تکنولوژی‌های استفاده‌شده
- نصب و راه‌اندازی
- نحوه استفاده
- ساختار پروژه
- بخش‌های اصلی

## ✨ ویژگی‌ها

### عملکردهای اصلی

- 👥 **مدیریت مشتریان:** ثبت و مدیریت اطلاعات مشتریان
- 🎭 **مدیریت رویدادها:** ایجاد، مشاهده و ویرایش رویدادها
- 🎫 **مدیریت بلیت‌ها:** ثبت و مدیریت بلیت‌های رزرو شده
- 💳 **مدیریت پرداخت‌ها:** ثبت پرداخت‌ها و تغییر وضعیت پرداخت (Paid / Unpaid)
- 🔢 **مدیریت شناسه‌ها:** جلوگیری از ثبت شناسه‌های تکراری
- 📊 **کنترل ظرفیت:** بررسی ظرفیت رویدادها و جلوگیری از رزرو بیش از حد مجاز

### رابط کاربری

- 🖥️ رابط گرافیکی دسکتاپ با استفاده از Tkinter
- 📋 نمایش اطلاعات در قالب جدول با استفاده از Treeview
- 🖱️ امکان انتخاب رکوردها از جدول
- ✏️ قابلیت ویرایش اطلاعات ثبت‌شده
- 🔄 به‌روزرسانی اطلاعات نمایش داده‌شده پس از عملیات

### مدیریت داده‌ها

- ✅ اعتبارسنجی اطلاعات ورودی
- 💾 ذخیره‌سازی اطلاعات با استفاده از Pickle
- 📁 نگهداری اطلاعات در فایل‌های محلی با پسوند `.dat`
- 🔒 بررسی ارتباط بین مشتریان، رویدادها، بلیت‌ها و پرداخت‌ها

## 🏗️ معماری پروژه

پروژه با استفاده از معماری لایه‌ای طراحی شده است تا مسئولیت‌های مختلف برنامه از یکدیگر جدا باشند.

```text
┌─────────────────────┐
│        View         │
│    رابط کاربری      │
└──────────┬──────────┘
           ↓
┌─────────────────────┐
│     Controller      │
│   مدیریت درخواست‌ها │
└──────────┬──────────┘
           ↓
┌─────────────────────┐
│    Business Logic   │
│     منطق تجاری      │
└──────────┬──────────┘
           ↓
┌─────────────────────┐
│     Data Access     │
│   دسترسی به داده‌ها │
└──────────┬──────────┘
           ↓
┌─────────────────────┐
│    Pickle Files     │
│   ذخیره‌سازی داده   │
└─────────────────────┘
```

## 🛠️ تکنولوژی‌های استفاده‌شده

- **زبان برنامه‌نویسی:** Python 3
- **رابط کاربری گرافیکی:** Tkinter
- **ذخیره‌سازی اطلاعات:** Pickle
- **معماری:** Layered Architecture
- **برنامه‌نویسی:** Object-Oriented Programming (OOP)

## 🚀 نحوه استفاده

پس از اجرای برنامه، پنجره اصلی نمایش داده می‌شود و می‌توان از بخش‌های مختلف برای مدیریت اطلاعات استفاده کرد.

### عملیات اصلی

- **Save:** ثبت اطلاعات جدید
- **Select:** انتخاب یک رکورد از جدول
- **Edit:** ویرایش اطلاعات رکورد انتخاب‌شده
- **Refresh:** به‌روزرسانی اطلاعات نمایش داده‌شده

## 📚 بخش‌های اصلی

### Customer
مدیریت اطلاعات مشتریان و ثبت مشخصات آن‌ها.

### Event
ایجاد و مدیریت رویدادها با امکان تعیین نوع رویداد، ظرفیت و قیمت.

### Ticket
مدیریت بلیت‌ها، ثبت رزرو و کنترل ظرفیت رویدادها.

### Payment
مدیریت اطلاعات پرداخت مشتریان و تعیین وضعیت پرداخت.
